# CRM Data Analysis Project
A data analytics project focused on analyzing CRM data to identify business trends, customer patterns, and actionable insights.

## 🛠️ Tools Used
- SQL
- Power BI
- Excel

## 📊 Project Components
- SQL data analysis
- Power BI interactive dashboard
- Business insights and visualization

## 📁 Project Files
- **SQL analysis documentation** – SQL queries and analysis
- **Power BI dashboard** – Interactive dashboard and visualizations
- **Project presentation** – Project overview and findings

## 🎯 Project Objective
The objective of this project is to analyze CRM data and transform it into meaningful business insights using SQL, Power BI, and Excel.
